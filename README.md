# Kurovani

Boutique de streetwear inspiré anime. Originals / Streetwear / Paris – Tokyo.

- `index.html` : la page boutique (hoodie à faire tourner en 3D, pièces, détails, guide des tailles, palette).
- `img/` : visuels des pièces.
- `archive/prototype-catalogue/` : premier prototype (grille catalogue avec filtres), gardé pour référence.

Ouvrir `index.html` dans un navigateur suffit pour voir le site. La conversion en thème Shopify viendra ensuite.
