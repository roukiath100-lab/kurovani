# Thème Shopify Kurovani

Branche dédiée au thème : Shopify peut s'y connecter directement.

## Installer
Admin Shopify > Boutique en ligne > Thèmes > Ajouter un thème > Connecter depuis GitHub,
puis choisir le dépôt `kurovani` et la branche `shopify-theme`.

## Conventions
- Produit : image 1 = face, image 2 = dos (le visuel se retourne).
- Fiche technique d'un produit : étiquettes au format `Nom: valeur` (ex. `Coupe: Oversized`).
- Kanji vertical d'un produit : champ méta `custom.kanji` (facultatif).
